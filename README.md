# ai-agent-infra-list

Curated open-source **AI agent infrastructure** — identity, protocols, tools, frameworks, memory, runtimes, observability — not the models themselves.

This is a **2026 refresh**: the old Frameworks / Planning / Memory / Tools taxonomy is replaced by a layered stack (identity, A2A tasks, MCP tools, UI, IDE, commerce, and so on). **ANP 1.1 / `did:wba`** sits in the identity / open-internet layer, alongside A2A and MCP rather than under them.
